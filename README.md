
# 🌟 MiniSocial – Social Media Web Application

**Assigned by: CodeAlpha**

## About the Project
MiniSocial is a social media web application developed using Python and Django. It allows users to connect, share posts, and interact with others.

## Features
- User Registration and Login
- Create and Share Posts
- Like and Comment on Posts
- Follow and Unfollow Users
- Stories Feature
- Notifications
- Bookmark Posts
- Profile Visitors Tracking
- Search and Explore Users

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
